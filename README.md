# 💱 Currency Converter

A responsive and user-friendly currency converter web application built using **HTML, CSS, and JavaScript**.

The application allows users to enter an amount, select the source and target currencies, and get the converted amount using exchange-rate data from the **Frankfurter API**.

## 🚀 Features

- 💰 Convert amounts between different currencies
- 🌍 Supports multiple currencies
- 🇺🇸 Dynamic country flags
- 🔄 Select From and To currencies
- 📊 Fetches exchange rates using an API
- 📱 Responsive design for desktop and mobile
- ✅ Input validation for invalid amounts
- ⚡ Simple and easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- Frankfurter API
